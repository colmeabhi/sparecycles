01 · how it works

From one big job to one answer you can trust.

The leader splits the job, volunteers pull the squares, and votes decide which results to keep.

01

Split

The job becomes squares of about 60 seconds each.

02

Pull

Volunteers ask for work. Each square goes to 3 of them.

03

Run

Each volunteer computes before its lease ends.

04

Vote

2 matching results win. The odd one is outvoted.

05

Merge

All squares join into one final result.

03 · use cases

Made for jobs that cut into squares.

Each square must run alone and give the same answer every time.

Great fit

  • Image rendering · fractals, frames, map tiles
  • Monte Carlo · each run is separate
  • Parameter search · one small model per square
  • Batch inference · one batch of inputs per square
  • Data preparation · one shard per square

Not a fit

  • Training one large model · machines sync many times a second
  • Games and live apps · need replies in milliseconds
  • Pieces that talk · one slow machine blocks the rest
  • Private data · squares run on other people's machines

Can you cut it into squares that each run alone and always give the same result? Then SpareCycles can run it.

04 · under the hood

Six distributed algorithms, written from scratch.

No consensus or gossip libraries. Each one is a small Go package behind a clear interface.

01

Leader election

Bully algorithm with terms. The highest live node leads, and only one leader acts.

internal/election■ done
02

Replication

Each task-table change reaches a backup before the leader confirms it.

internal/replication■ done
03

Gossip

SWIM probes and indirect pings find failed nodes with a fixed load per node. A dead volunteer's square moves on in seconds.

internal/membership■ done
04

Leases

Each square is lent, not given. When the lease ends, someone else gets it.

internal/lease#6
05

Majority vote

3 volunteers run each square. 2 matching results win. No majority means 2 more.

internal/verify#7
06

Resource discovery

Match squares to volunteer speed and trust, based on VECTrust.

internal/scheduler#8
05 · run it

A cluster on your laptop in a minute.

You need Go 1.27 or later. No config file is needed to start.

# get the code and run the tests
$ git clone https://github.com/colmeabhi/sparecycles.git
$ make -C sparecycles test

# one terminal each
$ make run-coordinator
$ make run-volunteer
$ make run-client

16/16 units done
done in 1.002s · saved result.png
  • Docker Compose. make up starts 3 coordinators, 3 volunteers and Prometheus. Stop the leader and another takes over.
  • Metrics. Jobs, units, leases, wrong results and elections on :9400/metrics.
  • One config style. Every setting is an SC_ variable with a safe default.
  • Tokens, session secrets and signed tasks. make keys, then only known volunteers join, nobody can act under another volunteer's ID, and volunteers run only tasks the leader signed.
  • Two workloads. Fractal tiles saved as a PNG, and a Monte Carlo estimate of pi saved as JSON: -workload montecarlo.
  • Your own workload. Write Split, Run and Merge, then register it.
  • AWS. Terraform for 3 zones and spot volunteers: make deploy-up. First run on AWS in progress (#15).
